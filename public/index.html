⚠️ PENTING AGAR DAFTAR COOKIE TIDAK KOSONG:

Pastikan Anda menekan F12 saat berada di tab Instagram (tab berlogo IG di browser Anda), BUKAN di tab ReelSnap (localhost). Jika membuka F12 di tab ReelSnap, daftar cookie akan kosong!

  1. Klik tab Instagram (tab di sebelah ReelSnap pada browser Chrome Anda).
  2. Tekan tombol F12 pada keyboard untuk membuka menu Developer Tools.
  3. Di menu atas Developer Tools, klik tab Application (jika tidak terlihat, klik tanda panah >> lalu pilih Application).
  4. Di panel sebelah kiri, cari Storage > klik Cookies > pilih https://www.instagram.com.
  5. Cari baris bernama sessionid, klik dua kali pada kolom Value, lalu tekan Ctrl + C (Salin).
  6. Kembali ke tab ReelSnap, tempel nilainya ke kotak di atas, lalu klik Simpan & Terapkan.
